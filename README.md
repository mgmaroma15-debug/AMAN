# AMAN Baby Care & Home Services — Prototype

Responsive React + Vite + TypeScript prototype inspired by the supplied reference.

## Features
- Responsive home page, service cards, about, packages, testimonials, FAQ and contact form
- English/Arabic language toggle and RTL Arabic layout
- Demo invoice with a mouse/touch signature canvas
- Browser print dialog to print or save the invoice as PDF

## Run locally
Install Node.js 18+ (Node.js 20 LTS recommended), then:
```bash
npm install
npm run dev
```
Open the localhost URL shown by Vite.

## Build
```bash
npm run build
npm run preview
```
Output is generated in `dist/`.

## Prototype limitations
- Images and fonts are loaded from external URLs; internet access is needed for them.
- Contact form is a front-end demonstration only and does not submit to a server.
- WhatsApp number, business email, prices, VAT, service content, invoice details and testimonial are sample content. Replace them with client-approved details.
- Invoice is marked DEMO ONLY. Signature is not verified or securely stored.
- No backend, database, customer accounts, real booking management, payment gateway, admin dashboard, legal e-signature or tax-compliance integration is included.
- Translations are manually authored sample content, not automatic machine translation.

## Deployment
Can be deployed as a static site to Vercel:
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

Before production, confirm content and translations with the client, replace demo contact details, implement any agreed backend features, and check applicable Saudi privacy and invoicing requirements.
